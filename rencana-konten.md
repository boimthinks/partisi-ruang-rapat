# Perencanaan Konten Website partisiruangrapat.web.id

Dokumen ini adalah peta jalan (content roadmap) produksi konten untuk rubrik **Teknis** (`/teknis/`) dan **Blog** (`/blog/`) pada website `partisiruangrapat.web.id`.

Pedoman pemisahan rubrik mengacu pada **`SUMBER-PENGETAHUAN.md` Bab 6**:
- **Proyek (`/proyek/`):** Portofolio nyata, social proof, foto asli 4:3 instalasi lapangan.
- **Teknis (`/teknis/`):** Engineering authority, sains akustik, rumus beban, struktur balok WF, mekanikal jack, standar RKS/TKDN (Target: Arsitek, Kontraktor, Konsultan Akustik, PPK).
- **Blog (`/blog/`):** Problem awareness, efisiensi sewa gedung, strategi zonasi modular, komparasi fungsional (Target: Pemilik Bisnis, GM Hotel, HR/GA Kantor, Rektorat).
